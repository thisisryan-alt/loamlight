# Loamlight

A 2D sandbox survival game: dig, build, craft, fight and explore a procedural world where darkness is a resource.
Built in Unity 6000.4.11f1 (URP 2D). Every asset, including sprites, tiles, sounds, music and fonts, is generated by scripts in `/Tools`.

## Play
- Build a player with `./Tools/unity.ps1 player`. For an optimised build, use `./Tools/unity.ps1 exec -Method Loamlight.EditorTools.PlayerBuild.BuildRelease`.
- Then run `Builds/Windows/Loamlight.exe`. Create a world from the menu, with a name, a seed and a size.

| Action | Default |
|---|---|
| Move / jump / drop through platforms | A D / Space / S (rebindable in Settings) |
| Use the held item: dig, build, attack | Left mouse (hold to repeat, drag to build lines; Shift-drag fills a rectangle) |
| Interact: doors, chests, beds | Right mouse |
| Inventory and crafting | E |
| Hotbar | 1–0 or the mouse wheel |
| Undo the last build | Ctrl+Z |
| Pause, save, settings | Esc |

## The world
- **Surface biomes:** Meadow, Dunes, Frostfell.
- **Underground:** the glowing Glowmire caverns, and the Emberdeep at the bottom of the world.
- **Liquids:** water and lava flow (where they meet, they make obsidian); sand and gravel fall; grass and moss spread.
- **Ore tiers:** copper and iron, then lumite (needs an iron pickaxe), then cinderite (needs a lumite pickaxe).
- **Structures:** buried cabins, dune shrines and Emberdeep vaults hold loot.
- **Enemies:** Gloops (day), Hollows (night), Duskbats (caves) and Cinder Imps (the Emberdeep). Each one telegraphs its attacks.
- **The boss:** craft a Wick Charm (anvil) and light it at night or deep underground to face the Gloamwarden, a three-phase boss that swallows the light.

## Development
- `./Tools/verify.ps1`: tests, the player build and every scenario (m1–m6 and perf), with checked screenshots.
- `./Tools/build_art.ps1`: regenerate all art and audio. Then run `./Tools/unity.ps1 setup` to import it.
- `PROGRESS.md` holds the milestone log; `DESIGN.md` holds the architecture and design decisions. Milestone screenshots are in `Docs/screenshots/`.
